# GitDemo Activity

## Project Folder Structure
- `/src`: Contains all source code.
- `/assets`: Images, icons, and static files.
- `/docs`: Documentation and lab notes.

## Component Layering Strategy
We are using a **Separation of Concerns (SoC)** strategy:
- **Presentation Layer:** Handles UI components and styles.
- **Logic Layer:** Manages data processing and business rules.
- **Data Layer:** Handles API calls and local storage interactions.
